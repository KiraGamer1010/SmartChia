# Sensores y adquisición de datos

| Categoría | Representación reportada | Tipo | Función en el proyecto |
| --- | --- | --- | --- |
| Turbidez | NTU | Variable física | Registrar el valor de turbidez del agua y consultar su variación temporal |
| Sólidos disueltos (TDS) | ppm | Variable física | Registrar el valor reportado de sólidos disueltos |
| Movimiento | Estado | Evento | Identificar detección o estado de movimiento y apoyar supervisión |
| Distancia ultrasónica | cm | Medición indirecta | Registrar distancia estimada mediante ondas sonoras |

Turbidez y TDS son variables diferentes. Movimiento no mide directamente la calidad fisicoquímica del agua. Distancia ultrasónica no es una medición directa de calidad; podría aportar contexto de nivel o posición, según el montaje.

El informe registra las unidades disponibles para cada categoría. Las fichas técnicas de los dispositivos pueden complementar esta descripción con marcas, rangos, precisión y calibración.
